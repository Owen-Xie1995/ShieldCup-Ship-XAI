控制組 seed 42 分數 **75.58758067203142**，第 21 階段 16×16 分數 **76.05259533915773**；後者只在 4/9 張圖改善，逐圖差值中位數為 −0.587575，故未獲判定為穩定勝出。本輪 8×8 結果不得依已知九張圖的 Id、檔名、人工輪廓或分數調整方法。

## 預先固定方法

對每次傳入的當前 `float32` NCHW 圖與指定目標，用完整 CHW 的 `b=min(x)` 及模型 eval/no_grad 的目標 logit。三通道各切成 28×28 個不重疊 8×8 tile，合計 2,352 塊；每次只把一通道的一塊 64 個 CHW 位置替換為當前圖片自己的 `b`，其餘位元組保持不變。將 `(z−z_mask)/64` 帶符號回填；完整 CHW 絕對值前 25% → 各通道 reflect 5×5 平均 → 完整 CHW 絕對值前 10%，維持符號。模型、指標與資料均不修改。

官方評估固定 seed 42、CPU、batch size 1、`shuffle=False`，各遮蔽輸入以 batch 32、PyTorch 執行緒 8 推論。內容定址快取把**未後處理的原始帶符號圖**及**最後歸因圖**分別存入同一分片，均帶 SHA-256；鍵綁定完整輸入、目標、權重、完整程式與遮蔽核心、參數及相關版本。中斷後僅可重用核對過的完整當前輸入分片；九圖 CSV 須由原版官方產生器完整重新生成。

## 雙輸入遮蔽探針

`probe.json`／`probe.log` 已記錄官方第一張轉換後圖片與一張獨立細微擾動圖。兩者各核對完整 2,352 個遮蔽輸入：每塊選中 64 個位置並填入當前圖片自己的 `b`，未選位置位元組不變，全部 tile 恰覆蓋完整 CHW 一次；首尾 tile 另以獨立模型 logit 核對帶符號回填值。原始與最後歸因均為有限 `float32`、shape `1×3×224×224`。原圖 `b=−2.1179039478302`、遮蔽耗時 **348.071 秒**、抽樣峰值 RSS **1,672,904,704 bytes**；微擾圖 `b=−2.1190736293793`、耗時 **340.772 秒**、峰值 **1,351,778,304 bytes**。探針狀態 **PASS**。

## 16×16 原圖熱區還原

在 Mac 上以官方九張圖的轉換後完整輸入與目標、Stage 21 快取規格與原程式 SHA-256 重算內容位址鍵，九張原圖均配對到已驗證的分片；未依分片順序猜 Id。`heatmaps/stage21_16x16/contact_sheet.png` 列出原圖、絕對值覆圖和紅正藍負帶符號圖；`heatmaps/observations.json` 有九張逐圖描述。多數亮區與船體或船上結構有重疊，但 Id 5 有明顯天空塊，Id 7 有天空、貨櫃與船體混合，Id 8 有前景船和碼頭／岸邊混合。手繪輪廓只供事後觀察，Id 7 的既有輪廓未完整涵蓋貨櫃。目視沒有像素精確船舶真值，不能據此宣稱解釋已合格。

## 論文線索

[Bhatt 等人的 Faithfulness 評估](https://www.ijcai.org/proceedings/2020/0417.pdf)與本機 Quantus 程式說明了隨機選 50 個分散 CHW 元素的指標；連續 8×8 tile 的 64 個元素並不等於這個擾動。[RISE](https://arxiv.org/abs/1806.07421)啟發下一個不同機制的候選：事先固定隨機重疊遮罩，在多種遮蔽上下文估計像素影響。這只是下一輪可檢驗假說，論文不能保證提高本輪船舶九圖分數；詳細證據、成本及替代方案見 `literature.md`。
