# 船舶影像 XAI：研究、交付與發表紀錄

這份作品集記錄船舶影像解釋方法的實驗、交付驗證，以及團隊投稿文件與口述報告的整理。

專案包含兩條研究工作：Mac CPU/MPS 上的 **4×4 有號遮蔽與 soft15 實驗**，以及破霧者團隊投稿的 **E017 分組路徑積分**。兩者的歸因方法和評分紀錄分開呈現。

團隊：破霧者，健行科技大學資訊工程研究所。v6 論文與簡報署名為謝富鈞、陳冠文、陳永翔，指導教授吳匡時；簡報提報人為謝富鈞。這裡保留共同作者歸屬，研究與投稿成果按團隊工作呈現。

## 公開版本範圍

此資料夾公開方法、彙整數據、檢核結論與講稿文字。原始 v6 DOCX/PPTX 含作者聯絡欄位及競賽影像插圖，完整檔案保留於本機；這裡省略個人聯絡資料與競賽影像。公開文字也已移除私人電腦絕對路徑。

口述稿保留對原始簡報圖表的指示，使用時須對照本機 v6 簡報。原始文件的 SHA-256 可用於辨識本次整理所依據的版本。

已有結果限於所記錄的模型、資料與環境。Jetson GPU 全流程仍待實機驗證；LOCAL 分數為既有 CSV 的本地公式算值，並非正式競賽成績。
